# CatchTheSun
CatchTheSun Комплексная система для многокритериальной оценки и ранжирования вариантов городской застройки на основе технико-экономических показателей и данных об инсоляции. Проект включает Backend на ASP.NET Core, Frontend-интерфейс, а также аналитические исследования, расчёты и отчётную документацию.
